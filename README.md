# mmcomputerhelp
Website for M&amp;M Computer Help

> Honest Advice. Practical Solutions. From a Real Person.

M&M Computer Help is an independent IT consulting and computer support business serving home users and small businesses throughout the Greater Tulsa area.

The goal of this project is to provide honest, practical technology assistance while building long-term relationships based on trust, integrity, and professional service.

---

## Website

This repository contains the official website for M&M Computer Help.

The website is built using:

- HTML5
- CSS3
- JavaScript

No frameworks or content management systems are required. The site is intentionally lightweight, fast, secure, and easy to maintain.

---

## Services

M&M Computer Help provides services including:

- Computer troubleshooting and repair
- New computer setup
- Technology consulting
- Computer purchasing guidance
- Malware and virus removal
- Security awareness and scam prevention
- Home networking and Wi-Fi setup
- Technology training and guidance
- Small business technology support
